# Pengenalan PHP

## Apa itu PHP?
* PHP adalah akronim dari **"PHP: Hypertext Preprocessor"**.
* PHP adalah bahasa skrip sisi server (*server-side scripting language*) sumber terbuka (*open source*) yang banyak digunakan.
* Skrip PHP dieksekusi di server.
* PHP gratis untuk diunduh dan digunakan.

## Mengapa PHP?
* **Lintas Platform:** PHP dapat dijalankan di semua platform utama (Windows, Linux, Unix, Mac OS X, dll.).
* **Kompatibilitas:** PHP kompatibel dengan semua server web terkemuka (Nginx, Apache, Cloudflare, Microsoft IIS, dll.).
* **Dukungan Basis Data:** PHP mendukung berbagai macam basis data (MySQL, PostgreSQL, MS SQL, DB2, Oracle Database, MongoDB, dll.).
* **Efisien & Mudah:** PHP mudah dipelajari dan berjalan secara efisien di sisi server.

## Apa itu File PHP?
* File PHP memiliki ekstensi file `.php`.
* File PHP dapat berisi teks, HTML, CSS, JavaScript, dan kode PHP.
* Kode PHP dieksekusi di server, dan hasilnya dikembalikan ke browser sebagai HTML standar.

## Apa yang Dapat Dilakukan PHP?
* Menghasilkan konten halaman web yang dinamis.
* Membuat, membuka, membaca, menulis, menghapus, dan menutup file di server.
* Mengumpulkan data dari formulir (*form*).
* Mengirim dan menerima *cookie*.
* Menambahkan, menghapus, dan memodifikasi data di dalam basis data Anda.
* Mengontrol hak akses pengguna.
* Mengenkripsi data untuk keamanan.

> **Catatan:** Dengan PHP, Anda tidak terbatas hanya pada output HTML. Anda juga dapat menghasilkan gambar, file PDF, atau format teks lainnya seperti XHTML dan XML.
